# SparkWright V5

现行评分标准为 `sparkwright-idea-v5.0.0`。只读取标题正文，四维各 3 项，等级 0–4 对应 0/30/55/80/100；维内权重 40/35/25，总分由服务端计算并显示一位小数。80+ 要求 P1/S1/F1 至少 3；90+ 另需四维原始值均至少 80、D2 为 4；S1/F1 明确为 0 时最高 49.9。缺少外部证明不扣分。

普通评分一次调用，格式最多修复一次。合成先生成 C，再用中性编号统一评分 A/B/C，正常两次调用；分数升降都保留候选，不设提升门槛。导入默认私人、不参榜，可复用本轮有效评分。普通评分保留缓存，合成每次主动点击生成新变体，支持耗时显示、手动取消，无短时业务超时。

评分、导入和普通发布都不自动参榜。作者主动加入；参榜需公开灵感及评分。正文修改暂时离榜，重评恢复；撤回公开、隐藏评分或管理下架取消参榜，恢复公开不自动加入。所有页面按当前正文最新有效 V5 分数显示，同分并列。

启动时守卫式迁移新增 `ideas.leaderboard_opt_in DEFAULT 0`、合成缓存字段和 V5 数据库触发器。V5 之前的旧分与旧合成只读归档，不改版本、不自动重评。已有 V5 合成保留原版本及结果，符合原有访问和评分校验时仍可导入。数据库回滚需停服务后恢复升级前的一致性备份；不要向旧代码直接套用已产生 V5 新数据的库。

开发检查：`npm run typecheck`、`npm test`、`npm run build`、`npm run smoke`。
真实模型语义、跨模型差异和耗时尚需实际测量；可选工具见 `eval-templates/scoring-v5/README.md`，不构成使用前置条件。

合成更新（synthesis-v5.1.0）：取消 3.0 分及机制/弱点改善准入门槛，允许分数升降；描述可概括改写，无逐字引用映射要求。每次点击采用随机组合方向生成新变体；取消“10分钟最多2次”限制，保留同账号单任务及服务端并发保护。评分制度、评分缓存和主动参榜规则不变。
