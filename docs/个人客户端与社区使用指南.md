# SparkWright 0.2：个人客户端与公共社区

电脑上的私人创作继续保存在本机；聊天和公开榜单由同一个社区服务维护。社区地址默认为 `https://community.sparkwright.asia`，新服务器尚未部署，暂时可以先使用本地功能。运营者在上线前应确认新 DNS 和证书后再发布实际社区地址。

## 电脑打开

安装 Node.js 22.12+，解压项目，双击 `启动SparkWright.bat`；或者在项目根目录执行 `npm.cmd ci`、`npm.cmd start`。窗口保持打开。出现登录页后：

1. 联网使用社区：注册昵称、邮箱和密码，或登录已有社区账号。无需邮箱验证码，也无需 SMTP。密码至少6位，UTF-8不超过72字节；owner 密码至少12位。
2. 离线创作：点击“先使用本地个人功能”。读写私人灵感不需要社区账号；AI 是否可用取决于你自己的模型供应商网络。
3. 左侧“公共社区”进入公共聊天。退出社区后，“我的灵感”、普通评分与合成继续可用。

4. 左侧或顶部“社区公告”进入云端公告，手机在公共社区的“公告”页查看。公告列表支持分页，打开详情会标记已读，也可单条或全部标记已读。已读只影响自己的社区账号，并在电脑与手机同步；公告和未读最多约60秒刷新一次。断网时提示连接失败，不显示本地公告作为替代。

社区 owner/admin 登录后，在“管理后台 → 公告管理”创建并保存草稿，再发布；支持编辑、撤下和分页。用户只能看已发布公告。编辑、撤下后重新发布会保留已有阅读状态；需要再次提醒时新建一条。正文是纯文本，动作按钮只支持安全 HTTPS 外链或站内根路径。电脑本地默认 owner 不能发布社区公告。

“目标”中只保留需求商单；心仪视频作品及视频分析、匹配功能已移除。历史数据未删除，仍随本机备份及历史数据导出保留。自媒体制作、作品内容和需求商单匹配不受影响。

“更多工具”和公共社区页脚提供 GitHub · Star 与 Watt Toolkit 官网入口。点击仓库链接后自行点亮 Star；应用不自动操作 GitHub。

本地身份与云端身份互不提权。登录昵称重名时以 `#账号ID` 区分；邮箱不显示在公开聊天。邮箱未验证，不提供依赖邮箱归属的自动找回或账号合并。

## 社区聊天

公共聊天连接后显示近实时在线人数。同账号的多个标签页/设备只计一人；关闭一个标签页不会误删其他连接。自动重连按消息 ID 补齐，发言重试使用同一请求编号，避免重复消息。最近50条先加载，更早的内容按游标翻页；界面最多保留300条，不强制打断历史阅读。

每条消息最多2000字，每账号每分钟最多20条，每账号最多4个连接。服务器当前总连接上限200，但这里只验证了20个连接，不构成200人容量保证。禁言、登出与过期会由服务端校验；连接权限变化最迟在约30秒检查周期内关闭。发送消息的权限立即校验。

## 公开灵感与参榜

在“公共社区 → 我的社区投稿”选择一条本地灵感，检查标题和正文，勾选确认后上传。上传先保存为云端草稿，其他作品、项目、私人评分和本地 Key 都不会上传。

在该页面的“社区专用 AI 配置”单独填写自己的供应商 Key、HTTPS Base URL 和模型。它保存在社区数据库中，只用于自己的社区评分，并消耗自己的供应商额度。运营者必须保护数据库及备份。服务端只接受配置白名单里的供应商；缺少 Key 时不会伪造评分。社区不默认提供作者的付费 Key。

依次执行“云端评分 → 公开正文与评分 → 自主参榜”。评分继续使用 V5 固定规则和一位小数；同分并列，稳定次序由服务端处理。原评分超过60秒或100.0分不参榜；60秒不是模型终止时间。修改上传正文会撤回公开与参榜，需对新正文重新评分；旧评分保留。社区评分每天最多10次尝试，仍保留引擎已有并发/调用限制。

可以撤回公开或退出榜单。所有已登录社区成员看到同一份有效榜单；手机可浏览、刷新和看公开详情。手机本期不提供本地私人创作与完整 AI 工作台。

## 手机打开

用手机浏览器打开社区 HTTPS 网址。注册/登录后使用聊天、排行榜、公开内容和反馈。登录 Logo 是静态图片；不会下载图标视频、Three.js 或完整3D模型。手机和电脑使用同一个社区账号体系。

## 反馈和管理

普通账号在“反馈”提交 Bug、建议或问题，并查看处理状态与公开回复。标题80字，正文10–5000字；不要填写 Key 或密码。

owner/admin 在社区页面出现“管理后台”后，可看在线连接、消息量、最近发言、连接异常、活动折线图及反馈收件箱。owner 另可禁言、管理角色、下架/恢复作品、改名或暂停/恢复唯一公共频道。内部备注不展示给用户。

“聊天活跃”按成功发言的普通账号去重；“社区活跃”还包括主动查看榜单/公开内容、投稿和撤回。过去24小时/7天/30天按滚动窗口去重，不相加每天人数。24小时图按小时、7/30天图按上海自然日；未采集区间留空。管理账号、登录、心跳、轮询不计活跃。不观察未联网的本地私人活动。

## 配置、备份与退出

- 社区地址只在本机 `.env` 设置 `COMMUNITY_URL`，生产连接要求 HTTPS；本地开发允许 loopback HTTP。不能在界面传入任意代理 URL 或请求头。
- 社区会话保存在本机服务内存；本机服务关闭即清除，不缓存密码。在线退出会撤销云端会话并关闭连接。网络不可用时退出仍清除本机会话，但无法宣称已完成远端撤销，远端凭据会按有效期到期。
- 本地升级前停止服务，备份 `.env`、`data/`。初次建立社区映射前另自动保存一致性快照到 `backups/`。保留旧用户 ID、Key 和评分；不要删库。
- 云端从空库重新部署，旧服务器没有备份，旧账号和聊天不会恢复。云端快照需定期复制到服务器之外并验证恢复。
- 完整多人工作台的旧包不再作为当前下载版本。当前交付是个人客户端包与轻量社区部署包。

## 开发检查

`npm.cmd run typecheck`、`npm.cmd test`、`npm.cmd run build`。`npm.cmd run build:community` 仅生成轻量网页；个人仓库不自动包含私有云端部署适配器。手机真实设备、互联网线路、供应商费用和生产 HTTPS/WSS 应在新主机上线时单独验收。
