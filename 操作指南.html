个人版网站打开操作指南

按下面 4 个步骤打开个人版。此页面保留 Word 原文的步骤与配图，双击根目录的 操作指南.html 即可查看，无需先启动应用。

Windows 一键启动：安装 Node.js 22.12+ 后，双击项目根目录的 启动SparkWright.bat。首次自动安装依赖，服务就绪后自动打开浏览器。请保持启动窗口打开；以下 4 个步骤是手动启动方式。

开始前：解压项目并安装 Node.js 22.12 或更高版本。打开后可登录公共社区，或点击“先使用本地个人功能”，无需登录即可创作。新版社区说明：个人客户端与社区使用指南。

01 打开文件夹 02 打开终端 03 输入指令 04 打开网址

01打开项目文件夹

进入解压后的 SparkWright 项目文件夹，确认当前目录中有 package.json。

02鼠标右键空白处打开终端（cmd命令行）

在文件夹空白处右键，选择“在终端中打开”。也可以在资源管理器地址栏输入 cmd，然后按回车。

如果打开的是 PowerShell（提示符以 PS 开头），使用下面的 npm.cmd 命令，无需修改系统执行策略。

03依次单行输入下列指令

先安装依赖，输入后按回车，等待安装完成：

npm.cmd ci

再启动应用，输入后按回车：

npm.cmd start

在 CMD 中也可使用原图里的 npm ci 和 npm start。等安装完成后再启动，看到“服务已启动”后继续下一步；保持启动窗口打开。

04打开网址，即可使用

在浏览器中打开下面的地址。选择社区登录，或点击“先使用本地个人功能”进入私人工作区：

http://127.0.0.1:5318

此网址需要先完成第 3 步。以后启动只需在同一项目文件夹运行 npm.cmd start，无需重复安装依赖。停止服务时，在启动窗口按 Ctrl+C。

社区上线后：公告与公共聊天

登录社区后，电脑点击“社区公告”，手机打开公共社区网址后点击“公告”，即可查看管理员发布的同一份公告。已读状态按社区账号同步；断网时仍可使用本机私人功能。管理员在社区“管理后台 → 公告管理”保存草稿，再发布。

心仪视频作品功能已移除，历史数据仍保留；自媒体制作与需求商单继续可用。启动 BAT 只运行个人客户端，公共社区由作者在服务器上维护，用户无需安装部署包。
